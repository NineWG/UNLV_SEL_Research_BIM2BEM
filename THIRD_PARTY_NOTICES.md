# Third-Party Materials and Attribution

This repository contains original workflow code and documentation together
with selected third-party reference materials needed to inspect the reported
case study. The MIT License in this repository applies only to original
repository materials; it does not replace the terms that apply to third-party
data sets.

## EnergyPlus Data Sets

GPTs/BIM2BEM_Enrichment/Schedules.idf is an EnergyPlus reference data set.
Its header states that it was derived from the BLAST Schedules Library and
includes building-type schedule patterns from ASHRAE Standard 90.1-1989,
Section 13. It is used as a reference library, not as evidence of current code
requirements or the actual operating schedule of the case-study building.

## Prototype and Weather Reference Files

GPTs/BIM2BEM_Enrichment/Library.zip contains prototype-model reference files
used by the enrichment workflow. Weather.zip and Weather_Data/ contain weather
and design-day resources used for reference and for the reported simulation.
These materials remain attributable to their original publishers and providers,
including the U.S. Department of Energy, PNNL, and EnergyPlus data resources,
as applicable.

third-party files.
