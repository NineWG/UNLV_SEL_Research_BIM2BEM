# LLM-Generated EnergyPlus Model

This directory contains the EnergyPlus model generated by the LLM-assisted
BIM2BEM workflow for the case study.

| File | Description |
| --- | --- |
| LLMGen_EP.idf | LLM-generated EnergyPlus 9.6 input data file. |
| LLMGen_EP.csv | EnergyPlus output data used for result inspection and plotting. |
| LLMGen_EPTable.html | EnergyPlus tabular-output report. |
| LLMGen_EP.err | EnergyPlus runtime and diagnostic log. |

Run the IDF with the weather files in ../../Weather_Data/ when reproducing the
case-study simulation.
