# EnergyPlus BEM Models

This directory contains the two EnergyPlus 9.6 models used for the reported
case-study comparison.

| Directory | Purpose |
| --- | --- |
| LLM_Gen_IDF/ | IDF generated by the LLM-assisted BIM2BEM workflow and its EnergyPlus result files. |
| Manual_Gen_IDF/ | Independently created manual reference IDF and its EnergyPlus result files. |

Each model directory contains an EnergyPlus input data file, a CSV output file
used for result inspection and plotting, an HTML tabular-output report, and an
EnergyPlus error log.

The two model directories are retained separately so that readers can inspect
the geometry and simulation-input representation of each model. The comparison
is model-to-model agreement for the case-study conditions, rather than
calibration to measured energy data.
