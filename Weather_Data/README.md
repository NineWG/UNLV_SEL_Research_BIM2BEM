# Case-Study Weather Data

This directory contains the weather and design-day files used for the reported
EnergyPlus simulations.

| File | Description |
| --- | --- |
| Selected_Weather_File_By_LLM.epw | TMY3 weather file for Las Vegas McCarran International Airport, Nevada, USA. |
| Selected_Weather_File_By_LLM.ddy | Corresponding EnergyPlus design-day file. |

Both the LLM-generated and manual reference IDF models should be run using the
same EPW and DDY resources for the case-study comparison.
