# Geometry Workflow Prompt and Output Screenshots

This directory contains case-study screenshots for the Geometry GPT workflow.
`Step_1.png` through `Step_7.png` illustrate the prompts and representative
outputs for IFC entity extraction, tracing, geometry filtering, surface
generation, boundary-condition assignment, EnergyPlus coordinate conversion,
and initial IDF generation.

The screenshots are provided for visual traceability. The corresponding
machine-readable workflow artifacts are stored in
`../../../BIM2BEM_Input_Output/Output/` and should be used for reproduction or
technical inspection.
