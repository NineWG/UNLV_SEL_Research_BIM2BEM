# BIM2BEM Workflow Input and Output

This directory provides the case-study IFC input and the intermediate and final
files produced by the LLM-assisted BIM2BEM workflow.

| Directory | Contents |
| --- | --- |
| Input | The source IFC model used as the workflow input. |
| Output | Intermediate JSON outputs, the initial Step 7 IDF, and the enriched final IDF. |

The output files provide traceability from the IFC input to the EnergyPlus-ready
IDF representation.
